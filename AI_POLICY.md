# AI policy

We welcome AI tools, including large language models, as aids for contributions to Z-Wave JS projects. Contributors remain responsible for everything they submit. Maintainers remain responsible for everything they merge and release. We hold all contributions to the same high standard, regardless of the tools used to create them.

Maintainers dedicate their time and expertise to reviewing contributions. Do not submit AI-generated content unless you have personally reviewed and understood it.

## Autonomous agents

**Autonomous agents may not contribute to Z-Wave JS projects.** We will close pull requests and issues that we believe were created autonomously. We may mark automated comments as spam. This rule also applies to contributions that bypass the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. You must review all content before posting it. Keep responses to the minimum needed to communicate your intent. We may hide comments that appear to contain unreviewed AI output.

When you open a pull request, you must be able to explain the proposed changes in your own words. This requirement covers the pull request description and responses to questions. If AI helped generate a pull request summary, review it for technical accuracy before posting it.

Do not use AI to generate the substance of answers to maintainers' questions. You must understand and be able to explain your own work. AI may help improve the grammar or clarity of your response.

If you include context from an AI interaction in a comment, disclose it and format it as a quote block with `>`. Add your own explanation of its relevance and implications. Do not share long excerpts.

## Non-native English speakers

AI can help people communicate in a language that is not their first language. You may use AI to improve the grammar or clarity of text you wrote. If AI translates your comments, make sure the translation accurately reflects your intent. You may include your original text in a `<details>` block to help maintainers verify the translation and keep the conversation readable.

## Code and documentation contributions

AI can help write code and documentation. Every contribution must have a human in the loop who understands the work produced by AI.

You must review and understand every change before submission. You must also be able to explain every code and documentation change in a pull request. Pull requests that appear to contain unreviewed AI output will be closed without review.

## Maintainer use of AI

Maintainers may use AI tools for code reviews, issue triage, reporting, and other project management tasks. These tools may leave comments on pull requests or issues. Their output can be wrong.

Treat an AI-generated comment like any other review comment. If you believe it is incorrect, say so and give a brief explanation. Maintainers have the final say. Ask a maintainer if you are unsure.

## Enforcement

We will close contributions that do not follow this policy. Repeated violations may result in a contributor being blocked from Z-Wave JS projects. If you believe we closed your contribution in error, contact a maintainer to discuss it.

This policy is adapted from the [Open Home Foundation AI policy](https://developers.home-assistant.io/docs/ai_policy).
